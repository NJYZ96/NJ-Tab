# NJ-Tab 4.5.1 修复说明

4.5.0 未发布。用户在审核 4.5.0 时实测发现严重问题，急修后直接升为 4.5.1 发布。

## 修复内容

1. 状态信息覆盖菜单（严重）：第二行状态组改为绝对定位后横盖在「配置」「查看日志」菜单上，两菜单无法点击。修复：状态组加 pointer-events: none，不再拦截点击；探针逐页验证各菜单中心点命中自身。
2. 旧状态残留：改版时漏删的旧元素 #usage 仍在显示旧格式「UsedSpace: 0.004mb」。修复：删除该元素与其写入代码。
3. 悬停重复提示：状态正文被原样复制进 title，悬停弹出与正文相同的内容。修复：不再设置该 title。
4. 查看日志移位（用户追加）：「查看日志」从第二行移到第一行「导入导出」之后、「回收站」之前，第二行只剩「配置」与状态信息。
5. 中英文排版规范（用户追加）：语言包中文版 55 条、英文版对应条目、代码内弹窗提示 6 处、仓库说明 7 处，统一为英文词与中文之间留空格、Gist / GitHub / Gitee 大小写规范（如「推送到 GitHub 的 Gist」）。
6. 导入文件名保留：导入备份成功后页面整页刷新会冲掉刚选的文件名，改为刷新后恢复显示。
