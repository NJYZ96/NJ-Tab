# NJ-Tab 4.5 需求审核清单（正式版，2026-11-20）

> 审核方法：逐条看，确认无误就在条目前打勾（把 `[ ]` 改成 `[x]`）；有意见写在每条下面的【】里面，没有意见可不填。
>
> 安装包：NJ-Tab-v4.5.1.zip（随汇报消息一同发送；4.5.0 未发布，已直接升到 4.5.1）。先在 3.1 侧做好留底再装这个包审核。

## 一、修复类

- [ ] 需求一 休眠打开整体失效修复：开启「休眠打开」、阈值调成 1，打开任意组，第 2 条起应为休眠状态；阈值 10 时前 10 条直开、其余休眠；休眠标签点开网址正确、无空白页。日志页「操作日志」区应能看到每组一条「休眠打开」结果。
【】


## 二、Gist 页

- [ ] 需求二 推送/拉取先验令牌再确认：没填令牌时点推送/拉取，直接报错提示填令牌，不弹二次确认；填了令牌才弹确认。GitHub、Gitee、推送、拉取都如此。
【】


- [ ] 需求三 令牌显示末 3 位：令牌保存后，输入框处能看到令牌最后 3 位，其余掩住。GitHub、Gitee 两处都是。
【】


- [ ] 需求四 去掉眼睛图标：Gist 页两个令牌输入框后面的「显示密码」眼睛图标已删除。
【】


- [ ] 需求五 自动备份状态两仓各一条：自动备份状态区 GitHub、Gitee 各显示自己最新的一条，不再互相顶掉。
【】


- [ ] 需求六 取消修改后自动同步：开启自动备份后，删改标签不再马上推备份；只按设置的频率定时备份。
【】


## 三、导入导出与日志

- [ ] 需求七 导出备份写日志：导出完整备份后，日志里有一条写清导出主列表多少组、多少条，回收站多少组、多少条。
【】


- [ ] 需求八 导入按组自带时间排序：导入备份后，导入的组按组自带的时间（建组时刻）插入到合适位置（新的在前），不再一律堆在最后；回收站导入同理。
【】


- [ ] 需求九 导入日志补条数：导入备份的日志写清导入多少组、多少条、去重跳过多少条（含回收站部分）。
【】


- [ ] 需求十 Gist 日志去重：推送/拉取后日志页同一动作只剩有详细信息的一条，没有详情的重复条不再出现。两个仓库、推送拉取都是。
【】


## 四、界面与列表

- [ ] 需求十一 状态提示改版：主页顶部状态显示「已存：N组 / M条标签 已使用：X MB（Y%）」；回收站显示回收站的组数/条数，体积与主页同一个数。顺带看一眼：各页面之间切换时，「查看日志」的位置不应左右漂移。
【】


- [ ] 需求十二 搜索提示字体自适应：把窗口拉窄，搜索框里的提示文字（搜索：输入后按回车…）字号会自动变小、尽量完整显示，不再被截断得只剩一半。
【】


- [ ] 需求十三 搜索词切页自动清空：在搜索框输入词后，切换到别的页面（主页、回收站、配置页等），搜索框里的词应自动清空；在搜索页本身词保留。
【】


- [ ] 需求十四 正式分页：主页、回收站、搜索页都改成正式分页（每页 50 组），有页码、上一页/下一页、首页/尾页和跳页输入，不再有「查看更多」；在第 2 页及以后，对组做锁定、删除、改名、拖拽，操作的应是眼前这一组、不串位。搜索页点跳转定位到某组时，应自动切到该组所在页并高亮。
【】


## 六、4.5.1 急修（2026-11-20 实测发现严重问题后追加）

- [ ] 急修一 菜单可点：主页、配置页、日志页等各页的「配置」「查看日志」菜单都能正常点开，不再被第二行的状态信息盖住。
【】

- [ ] 急修二 旧状态残留清除：各页不再出现旧格式的「已使用：0.000mb」字样；状态信息只剩新格式一行（已存：N 组 / M 条标签，已使用：X MB（Y%））。
【】

- [ ] 急修三 悬停不弹重复提示：鼠标停在状态信息上，不再弹出与正文一模一样的提示。
【】

- [ ] 急修四 查看日志改到第一行：「查看日志」已移到第一行「导入导出」后面、「回收站」前面；第二行只剩「配置」和状态信息。
【】

- [ ] 急修五 中英文排版规范：Gist 四个按钮改为「推送到 GitHub 的 Gist」「从 GitHub 的 Gist 拉取」「推送到 Gitee 的 Gist」「从 Gitee 的 Gist 拉取」；全插件文案已排查，英文词与中文之间留空格、Gist / GitHub / Gitee 等名称大小写统一（语言包 55 条、弹窗提示 6 处、仓库说明 7 处）。
【】

- [ ] 急修六 导入文件名保留：在导入导出页选好备份文件、导入成功页面刷新后，按钮旁仍显示刚导入的文件名。
【】
