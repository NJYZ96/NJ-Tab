## 背景介绍

0. 本项目由上游 N-Tab 定制演进，现统一更名为 NJ-Tab
1. 本项目是一个Chrome插件
2. 经过4年时间自用，敢保证永不丢失数据，速度超快，可存储数据超多，绝对是效率提升工具！
3. OneTab的平替，OneTab丢过数据的举手集合！

## 模拟使用场景
- 打开了N多Tab，每一个都不想关闭，浏览器已经到了点不了的情况，怎么办？--->一键收集起来慢慢看
- 今天上班为了解决某个问题/寻找某个选题，打开了很多相关的网站，但是要下班了，要关电脑怎么办？--->一键收集起来第二天一键打开
- 很多常用要打开的网站，浏览器自带的标签栏都放不下了？--->直接收集起来，置顶锁定，省心省力
- 可以做任务优先级分类，**紧急的事**，**重要的事**，**紧急但不重要的事**，**重要但不紧急的事**--->或者完全自定义
- 可以做历史时间线回顾，看看一个星期前，一个月前，都在看什么资料，关注什么内容

## 支持多款浏览器
- 支持 Chrome、Edge 等 Chromium 内核浏览器；本插件暂未上架应用商店，请按下方「安装方法」从本仓库下载安装

## 快速使用

- **PS：** 不想看长篇大论的介绍和功能说明，直接看[安装方法](#安装方法)
- 点击插件图标，会打开后台管理页
- 在任何打开的网页（包括本地打开的文件，如PDF，视频，照片），空白处直接右键点击，找到NJ-Tab，有多种功能可选
- 在任何打开的网页（包括本地打开的文件，如PDF，视频，照片），按快捷键Ctrl+Q，可以**发送所有标签**
- 在任何打开的网页（包括本地打开的文件，如PDF，视频，照片），按快捷键Alt+Q，可以**发送当前标签**
- 如需要定时备份功能，请配置 GitHub 或 Gitee 的 token，可二选一或全配置
- [查看全功能介绍（详细啰嗦版）](README_ALL.md)
- 本插件已内置暗黑模式和宽屏两列布局：点管理页顶栏的主题图标按钮即可轮换切换（白天 → 晚上 → 自动），默认是自动（跟随系统）

## 安装方法

1. 或者直接下载[最新的crx或zip](https://github.com/NJYZ96/NJ-Tab/releases)文件，右键选择解压缩到文件名，不要解压缩到当前目录，或者直接下载源码；

2. 打开Chrome浏览器或其他支持Chrome内核的浏览器，找到并点开“扩展程序”项；

3. 在打开的新页面中，勾选“开发者模式”，点击“加载已解压的拓展程序”按钮；

4. 从打开的“浏览文件夹”窗口中，选择第1步解压缩的的文件夹，点击“确定”按钮；

5. 此时该插件就正式启动了，观察浏览器右上角是否有新的插件图标，新版Chrome浏览器要手动固定才会显示。

6. 建议插件安装成功后，关闭开发者模式。

7. 现在就可以正常使用了，假如需要备份功能，先[获取 GitHub 和 Gitee 的 token](#获取token方法)，在管理页顶栏的「Gist 备份」页里填写 token（填完自动保存），并在同页打开“自动备份到 Gist”开关；

8. 2个备份平台，可以同时配置，也可以只配置1个，不冲突，假如选了自动备份，会自动无感知的**定时**备份到2个平台里（请先手动备份一次，通过查看日志，检查链路是否通顺），注意：Gitee特别设置了只要有修改就无感知自动**实时**备份，也就是说只要有修改，删除，移动等动作，就自动实时备份到 Gitee，选 Gitee 更保险，真.理论上永不丢失数据。

## 获取token方法
### Gitee
- 打开[Gitee](https://gitee.com/)，登录后
- 打开[私人令牌](https://gitee.com/profile/personal_access_tokens)
- 右上角生成新令牌，输入一个看起来有意义能明白啥用途的名字，比如： my-onetab-syncing-settings ，注意只勾选gist(可Ctrl+F搜索一下)，其他的不要勾选，
- 提交后，输入密码，生成后，要把显示的token另外找地方备份记录一下，只有在第一次创建的时候才会显示的，错过了只能重来。

### GitHub
- 打开[GitHub](https://github.com/)，登录后
- 打开[私人令牌](https://github.com/settings/tokens)
- 右上角选择Generate new token (classic)，输入一个看起来有意义能明白啥用途的名字，比如： my-onetab-syncing-settings ，注意只勾选gist(可Ctrl+F搜索一下)，其他的不要勾选，
- 提交后，输入密码，生成后，要把显示的token另外找地方备份记录一下，只有在第一次创建的时候才会显示的，错过了只能重来。


## 暗黑模式开启方法
- 本插件已内置暗黑模式：进入后台管理页，点顶栏的主题图标按钮即可轮换切换（太阳=白天、月亮=晚上、日月各半=自动），默认是自动（跟随系统），无需再改浏览器设置。

## 相对原项目（上游 N-Tab）的改进

NJ-Tab 在上游 N-Tab 3.1 的基础上做了持续改进（4.1、4.2、4.3、4.4、4.5），主要变化如下：

**界面与操作**
- 顶部改成一整行独立功能行（学 OneTab 的排法：品牌固定在最左、主题与菜单固定在最右、搜索框居中自适应填满），功能行在正常排版里实占一行、永不悬浮遮挡内容，中等宽度窗口下也不会再折行压住搜索框和页面顶部；品牌旁有 GitHub 仓库图标（新标签页打开本仓库）
- 宽屏列表改为最多两列的卡片式排版：每组带边框、高度见缝插针填满，不再被同行最高的组撑出大片空白；两列整体居中、组内左对齐
- 每条标签后面显示它自己的添加时间（拖拽、删除、还原、恢复都不改变）；回收站分组栏显示删除时间和剩余保留天数
- 搜索框带清空按钮（×），点一下清空搜索词并恢复完整列表；回收站也有自己的搜索框，只搜回收站内的数据
- 回收站的分组菜单精简为打开整组 / 删除整组 / 还原整组三项
- 「已保存」提示改到页面上方中央显示
- 菜单按功能重新分组，二级页面各归其位：Gist 备份页（令牌、推送/拉取、自动备份都在本页）、WebDAV 页（地址/账号/密码、连接测试、上传/恢复、自动备份都在本页）、导入/导出合并为一页、配置页（只放通用开关）、日志页
- 所有配置改完自动保存，不再有“保存配置”按钮
- 主题切换改成单个图标按钮轮换（白天 → 晚上 → 自动），默认自动
- 暗黑模式与宽屏（带鱼屏）两列布局
- 状态信息精简为一行小字：“已存：N组 / M条标签 已使用：X MB（Y%）”（百分比以 10MB 为基准，本插件实际不受此上限限制），进回收站后显示回收站的组数/条数、体积口径相同
- 鼠标中键点击标签条目可在新标签页后台打开（左键行为不变；“打开时删除”只对左键生效）
- 全局搜索、标签组备注、恢复标签时可休眠打开（4.5 加固：点开整组时现读开关与阈值设置，休眠后逐个回查确认、失败自动重试，每组打开结果会写一条日志）
- 拖拽排序流畅度优化，拖完不再整页重渲染；两列排版下拖组、拖条均已实测正常
- 删掉了划词翻译和顶部的“多谢投喂”菜单
- 与商店版 3.1 同时安装时，两个版本的管理页互不抢占（各认各的页面）
- 搜索改为独立页面：在搜索框输入后按回车进入，搜索结果每条标签可直接删除、或点跳转定位到它所在的那一组（自动切到该组所在页）；锁定组里的条目先点小锁解锁（只当次有效）再删；搜索页与主页、回收站一样改成正式分页（每页 50 组，带页码、上一页/下一页、首页/尾页和跳页输入）；切换页面时搜索框里的词会自动清空；搜索框的提示文字字号随窗口宽度自适应
- 主列表锁定组里的单条标签前面显示小锁，可单独解锁这一条当次删除，不必把整组解锁；删除整组只保留组标题前一个入口，组锁定后该按钮变小锁，点小锁或菜单里的「取消锁定」都能解锁
- 拖拽标签与拖拽标签组不再互斥、也不再有模式开关：抓标签拖是移标签（可跨组），抓组标题拖是调组顺序，随时可用
- 品牌名下方显示当前版本号，点击打开本仓库的 Releases 总页面
- 切页时顶栏菜单位置固定不动（组数状态隐藏时保留占位）

**性能（按 3 万条标签实测优化）**
- 列表分页显示：每页 50 组，避免一次画出上万条导致页面卡死；搜索仍是全量搜索（3 万条里最后一条也能搜到，实测约 0.15 秒）
- 锁定、置顶、改名、删除等只改一处的操作改为局部更新 + 合并保存，不再每次全量重存、全量重画；3 万条数据下首屏（含一次性数据转换）约 4 秒打开，锁定/删除点击后约半秒内画面生效

**备份与恢复**
- 备份文件名统一为 `NJ-Tab-Backup-YYYYMMDD-HHmmss`（本地导出、网页单文件、WebDAV 三类同规，精确到秒防重名覆盖）
- 所有备份（网页单文件除外）包含插件配置（主题、开关、间隔与保留规则等），恢复时一并恢复；WebDAV 地址/账号/密码和两个令牌永不进入任何备份
- 单文件导出（网页版/完整备份）与完整备份导入，导出不再丢时间信息；文本导出带每条标签的添加时间，导入时可读回（没有时间字段的旧文本照样能导入）
- 完整备份导入改为逐条检查：个别标签损坏（比如网址为空）只跳过那一条，并在日志里写清是哪一组、哪一条、什么问题，不再因为一条坏数据整份拒绝导入；导入的组按组自带的时间插进现有列表（新在前，不再一律追加到末尾），回收站同理；导出与导入都会在日志里写清组数与条数
- OneTab 文本导入修复：文件末尾没有空行时最后一组不再丢失
- Gist 备份：GitHub/Gitee 手动推送/拉取（点按钮先检查令牌、没存令牌直接提示，不再先弹确认框；令牌保存后会显示末 3 位便于辨认）；自动备份频率可调（5/15/30/60/120 分钟五档，默认 30 分钟），只按频率定时执行、修改数据后不再立即自动同步，数据无变化时自动跳过并给出提示，被限流会记进日志；自动备份状态按 GitHub / Gitee 两行分开显示
- Gist 与 3.1 原版彻底分开：新版可以从旧版的 Gist 拉取数据并自动完成转换（这是从 3.1 正式迁移的路），但推送只写新版自己的 Gist（文件 NJ-Tab_Tabs.json），绝不覆盖、改动旧版的备份
- 导入去重：备份文件导入与文本导入（默认格式 / OneTab）逐条判重——网址和标题都与已有标签相同才算重复、跨组也算，重复的跳过不导入，跳过条数会写进导入结果提示和操作日志；导入页有常驻的去重规则说明（WebDAV 恢复与 Gist 拉取是覆盖式同步，不去重）
- WebDAV 多版本备份：每次备份是带时间戳的新版本文件，可按保留天数/份数自动清理旧版本；有连接测试按钮；自动备份默认间隔 12 小时；恢复时列出全部版本（文件名、时间、文件大小），每个版本可单独删除
- 覆盖类操作（Gist 推送/拉取、WebDAV 恢复）改用页面内两步确认弹窗（第二步输入字母 Y）；WebDAV 恢复前会强制先备份当前数据，强制备份失败立即中止
- 回收站按保留天数自动清理（天数可设）

**安全与日志**
- 密码与 token 改为 AES-GCM 本机加密存储，老版本明文在首次读取时自动迁移，设置页不回填明文
- 删除了原版自带的全部统计代码（百度统计），打开管理页不再向任何统计服务发送请求
- 安全修复：Gist 推送的数据里不再夹带本机加密钥匙、操作日志与 WebDAV 密码（4.1～4.3 的老问题，4.4 已修复；令牌本身一直未进入过推送数据）
- 操作日志增强：Gist 推送/拉取、WebDAV 上传/恢复、导入、导出、自动备份（含跳过、含被限流）、回收站自动清理、恢复前强制备份、数据转换等关键动作都会记录成功/失败与简短原因；同一次 Gist 操作在日志页只保留带步骤详情的那一条，不再重复显示；日志带自动清理（可按保留天数/条数设置），且绝不记录密码、令牌原文
- 日志页按 Gist 备份 / WebDAV / 导入导出 / 操作日志四个区展示，每区先显示最近 5 条、可展开查看更多，每条一行（时间 + 动作 + 结果），点开条目看详情（过程日志的步骤收在详情里）

## 安全说明

- WebDAV 密码只保存在你这台电脑的浏览器里，只会在连接你的 WebDAV 服务器时用来登录，不会发到其他地方。
- 密码与令牌只在本机加密保存，不会明文存放，也不会进入任何备份、导出或 Gist。提醒：浏览器插件没有系统级保险箱，本机加密主要防止明文被直接看到或抄走，不能保证绝对安全。
